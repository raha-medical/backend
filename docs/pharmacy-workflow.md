# الصيدلية: العلاجات والمراجعون بدون مخزون

لا تتغير قاعدة البيانات ولا يضاف مخزون. `quantity` هي كمية المريض في عملية التسعير أو البيع المباشر (1–1000 لكل سطر)، والسعر المعروض في الكتالوج للوحدة. تبقى الأسعار من الخادم، وتسري التغييرات على الطلبات الجديدة فقط.

## كتالوج علاجات الفرع

- `GET /api/v1/pharmacy/drugs`: صلاحية `pharmacy.dispense` أو `pharmacy.view`، أدوية فعالة من فرع التوكن فقط، والرد `{items: ServiceDto[]}`.
- `POST /api/v1/pharmacy/drugs`: صلاحية `pharmacy.dispense` و`Idempotency-Key`، ينشئ خدمة بنوع `pharmacy` فقط ويعيد 201.
- `PATCH /api/v1/pharmacy/drugs/{service_id}`: صلاحية `pharmacy.dispense`، تعديل علاجات الفرع الحالي فقط؛ نوع آخر يُرفض بـ403، وفرع آخر بـ404.

حقول الكتابة: `name`, `price` (عدد صحيح 0–100,000,000), `currency` (`IQD|USD`), `requires_prescription`, `reason`. تبقى صلاحيات `/services` العامة دون تغيير. سجل التدقيق الحالي يسجل الإضافة وتغيير السعر.

## مراجعو الصيدلية المباشرون

البيع والتسليم يستخدمان المسارات الحالية `POST /pharmacy/external-sales` و`POST /pharmacy/external-sales/{invoice_id}/deliver`. يبقى الاسم والهاتف مطلوبين للملف الجديد، وتبقى متطلبات صورة الوصفة أو الملاحظة للأدوية المقيدة، ويُرفض التسليم قبل الدفع بـ402.

أضيفت القراءة بصلاحية `pharmacy.dispense` أو `pharmacy.view`:

- `GET /api/v1/pharmacy/external-sales`: معاملات `q` للاسم/الهاتف/الملف، `status=billed|dispensed` اختياري، `page`, `page_size`. الرد `PagedResult<ExternalSaleSummary>`: `invoice_id`, `patient_name`, `file_number`, `phone_number`, `created_at`, `status`, `amount` بالدينار. `billed` يعني انتظار الدفع أو التسليم، وليس إثبات عدم الدفع. الفلتر قبل الترقيم والعدد الكلي، والبيانات لفرع التوكن فقط.
- `GET /api/v1/pharmacy/external-sales/{invoice_id}`: الرد `PharmacyBillDto` الحالي، لإعادة فتح الطلب ومتابعة التحصيل والتسليم. فاتورة داخلية أو من فرع آخر تُرفض بـ404.

## الواجهة

قائمة الصيدلية تفصل «إحالات الأطباء» عن «مراجعون مباشرون». إحالات الأطباء تحتفظ بمراحل الوارد والحاضر والمكتمل. فتح الوصفة من زر «صرف» أمام اسم المراجع، دون إدخال كود أو كاميرا أو QR. المسار القديم `/staff/pharmacy/scan` باقٍ للتوافق مع الروابط، لكنه يعرض اختيار المراجع أو وصفته المختارة فقط. رموز الوصفات الداخلية في API والإيصالات لا تتغير.
